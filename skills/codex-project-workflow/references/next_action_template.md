# Optional `NEXT_ACTION.md` Template

Use this one-page project-state entry only when the repository opts in. It records local state; it is not canonical skill content and must not copy this skill's instructions.

```markdown
# Next Action

- Updated: <date or commit context>
- Current branch / working context: <branch or non-git context>
- Immediate next action: <one concrete action>
- Active task source: <task package or Task Card path>
- Latest validation: <command and result, or not run>
- Blockers / decisions needed: <concise list or none>
- Handoff notes: <only facts required for the next operator>
```

Replace stale state rather than accumulating a history. Keep durable project history in the repository's chosen status, handoff, or task-package surface.
