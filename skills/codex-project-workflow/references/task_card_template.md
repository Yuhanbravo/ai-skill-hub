# Task Card Template

Keep the Task Card short enough to restate before work begins. Link to the task package instead of copying its background.

```markdown
## Task Card

- Task: <short name>
- Type: <docs-only | implementation | evidence-only | preflight-only | review-only | closure | takeover>
- Objective: <one or two sentences>
- Source inputs: <AGENTS.md, task package, NEXT_ACTION.md, status docs, or none>
- Authorized paths: <paths>
- Forbidden paths: <paths or no additions>
- Expected output: <artifact, finding, or change>
- Validation: <commands or readonly evidence>
- Final report: <required fields or receiving audience>
- Risks / assumptions: <only active items>
```

Before editing, confirm that the type, authorized paths, forbidden paths, and validation command agree with the controlling task package. If they do not, record the conflict and stop for direction.
