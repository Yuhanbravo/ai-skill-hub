# Codex Project Workflow

`codex-project-workflow` is an instruction-only canonical skill for making individual Codex repository rounds repeatable: classify the task, use a short Task Card, establish fixed boundaries, preflight before edits, and close with a compact handoff report.

Use [SKILL.md](SKILL.md) as the canonical instruction source. The reference files provide reusable formats without imposing a project-local runtime pack or a mandatory `NEXT_ACTION.md` file.

The skill complements rather than replaces `chatgpt-handoff-pilot`, `workflow-bootstrap`, `project-takeover`, and project-local instructions. It keeps canonical workflow assets in `ai-skill-hub`; business repositories retain their own state, task cards, validation commands, and business constraints.
